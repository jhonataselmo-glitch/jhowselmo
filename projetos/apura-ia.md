# Apura.IA

**Dados públicos, geografia e visualização eleitoral.**

[Acessar Apura.IA](https://apura-ia-jslabs.pages.dev/)

## O projeto

Interface para acompanhar resultados eleitorais utilizando dados públicos do TSE, navegação por localidades e mapa interativo. O objetivo é tornar a leitura dos resultados mais clara.

## Minha atuação

- Concepção e evolução da interface.
- Organização da navegação por Brasil, estados e municípios.
- Desenvolvimento e revisão das visualizações e interações com o mapa.
- Evolução do projeto com apoio de IA e conferência das entregas.

## Competências demonstradas

Visualização de dados, interfaces web, mapas interativos, integração de dados públicos e publicação web em Cloudflare Pages.

## Status

Projeto publicado. Dados eleitorais devem ser interpretados conforme a eleição, a fonte e o momento de atualização; esta apresentação não atesta operação em tempo real.

Este arquivo apresenta o projeto no portfólio. Não contém o código completo da aplicação.
